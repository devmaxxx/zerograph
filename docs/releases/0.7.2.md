# zerograph 0.7.2

The release notes for the GitHub release page. The why behind each change is in the docs each line
links to.

## New

- **Claude Code says when a repository wants zerograph and it is not installed.** A teammate who
  gets the plugin from a repository's project settings but has no zerograph binary used to get a
  silent session start. In a checkout that asked for an index, built or not, with no binary to run,
  the hook now shows the person a message in the update notice's style naming the npm and pnpm
  install commands, and tells the agent in one context line that the graph tools are unavailable
  until it is installed. A repository that never asked stays silent; Codex gets the context line
  only ([keeping fresh](../keeping-fresh.md)).
- **A session that runs an older zerograph than the machine has says so.** A session keeps the MCP
  server it started with, so after `npm i -g zerograph` or `pnpm add -g zerograph` the old binary
  goes on serving. `mcp.mjs` asks the binary its version at start and, when the file it resolved
  to has moved and reports another release, begins every tool result from then on with

  ```
  zerograph was updated to 0.7.3 (this session runs 0.7.2) — restart the session or run /reload-plugins
  ```

  Nothing is stopped or restarted, and every other line passes through unchanged
  ([MCP](../mcp.md)).

## Changed

- **The plugin stands down only for the project Claude Code runs.** While a repository still
  commits a 0.6.x zerograph hook, the plugin's hook stays silent on the events it answers only when
  the session's project directory (`CLAUDE_PROJECT_DIR`) holds both the script and the
  `.claude/settings.json` entries that run it. A main worktree's copy, or a nested clone's, no
  longer silences a linked worktree whose branch retired the hook. At session start a stand-down
  still shows the not-installed and newer-release notices, which the old hook has no word for
  ([install](../install.md)).
- **A checkout's own index opts it in.** A main checkout that asked for nothing but has a built
  index of its own now counts as wanting zerograph, so it hears the not-installed notice too;
  before, only a linked worktree's main index counted.
- **The MCP launcher exits once the server's stdout has closed**, so the last tool result is never
  cut.
