# zerograph 0.6.4

The release notes for the GitHub release page. The why behind each change is in the docs each line
links to.

## Fixed

- **`install-agent --claude` keeps a matcher you narrowed.** A re-run replaced zerograph's hook
  entries whole, so a `matcher` a repository had changed on purpose (PreToolUse without `Bash`, say)
  went back to the default on every upgrade. The entry is still updated and its matcher kept, with a
  note naming the default it hides. A matcher an earlier release wrote still moves to the current
  default, so a hook that needs a wider matcher reaches every install that never changed it.
