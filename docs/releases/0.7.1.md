# zerograph 0.7.1

The release notes for the GitHub release page. The why behind each change is in the docs each line
links to.

## New

- **zerograph says when npm has a newer release.** Once a day an interactive run asks
  `https://registry.npmjs.org/zerograph/latest` on a thread no command waits for, with a 2 s
  timeout, and keeps the answer in `~/.cache/zerograph/update.json`, one entry per installed
  release. A run that ends before npm answers is retried within the hour; only an answer stamps the
  day. When the cached answer is newer than the binary, the run ends with a box on stderr, in
  colour on a terminal that takes it:

  ```
  ╭────────────────────────────────────╮
  │                                    │
  │   Update available 0.7.1 → 0.7.2   │
  │    Run npm i -g zerograph@0.7.2    │
  │   or pnpm add -g zerograph@0.7.2   │
  │                                    │
  ╰────────────────────────────────────╯
  ```

  `mcp`, `serve`, `status` and any `--json` run neither ask nor print, nor does a run whose stderr is
  not a terminal or one with `CI` set ([install](../install.md#a-newer-release)).
- **Claude Code shows it too, without asking npm.** At session start the plugin reads the same
  file, asks the binary it runs for its version, and when that release's entry names a newer one
  shows the person

  ```
  ▲ zerograph 0.7.2 available (you have 0.7.1)
    npm i -g zerograph@0.7.2 · pnpm add -g zerograph@0.7.2
  ```

  with one line for the model in the brief; the hint under the prompt ends in `↑0.7.2`. Codex gets
  the brief line only.
- **`status` reports the cached release.** `zerograph status` and the MCP `status` tool print an
  `update:` line, and `status --json` carries it as `update` (absent or `null` when there is none),
  read from the cache and never fetched.
- **Two ways to turn it off.** `ZEROGRAPH_NO_UPDATE_CHECK` or `NO_UPDATE_NOTIFIER`, set to any
  value, stops the check, the box, the `status` line and the plugin's message and marker.
  `NO_COLOR`, `CLICOLOR=0` or `TERM=dumb` draws the box plain
  ([configuration](../configuration.md#update-notices)).

## Changed

- **New crates.** `update-informer` 1.3.0, built with its npm registry over `ureq` and `native-tls`,
  which are the versions `hf-hub` already brings, so no second HTTP or TLS stack is built. It adds
  `etcetera` and `home`, and on Windows a second `windows-sys` (0.59).

## Before upgrading

- **A Cargo or archive install gets no notice of its own kind.** The box and the plugin name npm and
  pnpm whichever way the binary was installed; update a Cargo or archive install the way it was
  installed, or set `ZEROGRAPH_NO_UPDATE_CHECK`.
